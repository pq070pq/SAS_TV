# TV Debug Assistant 0.1

تطبيق Android TV تجريبي لتشخيص معلومات الجهاز ومحاولة فتح صفحات إعدادات المطوّر الرسمية.

- متوافق بنيويًا مع Android 6.0+ ويستهدف Android 9 وما قبله عبر targetSdk 28.
- يعرض الشركة والطراز وإصدار Android ومستوى API.
- يوفر اختصارًا لصفحة خيارات المطوّر وإعدادات النظام.
- لا يغيّر adb_enabled ولا يستخدم Root ولا يتجاوز صلاحيات الشركة المصنّعة.

## البناء
يُبنى عبر GitHub Actions من workflow باسم **TV Debug Assistant APK**. بعد نجاح التشغيل، نزّل Artifact باسم **TV-Debug-Assistant-0.1**.

هذه نسخة تشخيصية أولية؛ لا تدّعي تفعيل ADB تلقائيًا.
