# SAS Calculator PRO for Android
Standalone Android Studio project, placed under this repository in its own folder.

## Features
- iOS-inspired circular keypad and dark layout
- Basic arithmetic, percent, sign, delete, decimals, history
- Scientific mode
- Currency conversion using Frankfurter reference rates (internet required)
- Math Notes starter with arithmetic expression and basic graph plotting

## Build
Open this folder as a project in Android Studio, or run the repository workflow:
GitHub Actions > Build SAS Calculator PRO APK > Run workflow.

The APK is uploaded as a workflow artifact named SAS-Calculator-PRO-APK.

## Limitations
This is an independent implementation inspired by familiar iOS calculator patterns, not Apple's proprietary app or assets. Math Notes is an initial implementation and does not yet provide Apple's complete symbolic equation solver/graphing feature. Currency rates are indicative reference rates and may not match bank/card execution prices.
