# SAS-TV

تطبيق Android TV واحد مستقل بواجهة عربية RTL، مستوحى من تجربة UrTV ومهيأ ليكون الشاشة الرئيسية الافتراضية عند اختياره من النظام.

## سلوك التثبيت واللانشر
- ينتج المشروع **APK واحدًا فقط** باسم SAS TV.
- يظهر التطبيق في قائمة تطبيقات التلفزيون، ويعلن أيضًا عن نفسه كخيار لتطبيق HOME.
- عند الضغط على زر Home أو من إعدادات التطبيقات الافتراضية، يمكن اختيار SAS TV ليحل محل واجهة الشركة المصنّعة.
- أندرويد قد يعرض شاشة اختيار اللانشر؛ لا يمكن ضمان تعيينه افتراضيًا بصمت بمجرد التثبيت.
- لا نحذف لانشر الشركة المصنّعة ولا نعطّله؛ يمكن الرجوع إليه من إعدادات النظام أو تغيير تطبيق Home الافتراضي.
- شاشة التوقف مدمجة كوحدة Android library داخل التطبيق نفسه؛ لا يوجد APK ثانٍ أو تطبيق جوال مرافق.

## المشروع والمصدر
العمل مستلهم من مستودع [tshi-dev/UrTV](https://github.com/tshi-dev/urtv)، مع اعتماد حزمة Android واحدة. لا ننسخ سكربتات الإعداد التي تعطل تطبيقات النظام أو تتطلب ADB/root.

## المبادئ
- العربية وRTL افتراضيًا.
- دعم الريموت ولوحة المفاتيح واللمس.
- واجهة خفيفة للأجهزة محدودة الموارد.
- لا روت ولا أوامر ADB ولا تعطيل أو حذف لتطبيقات النظام.
- لا بيانات طقس أو صلاة أو أخبار وهمية.
- لا يُعلن عن APK جاهز قبل نجاح البناء والاختبارات والتحقق من التثبيت.

## الوحدات والبناء
يتكون المشروع من وحدة التطبيق `:app` ووحدة ميزة داخلية `:feature:screensaver`، وتندمجان في ملف APK واحد:
`:app:assembleDebug`
