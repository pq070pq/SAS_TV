# SAS-TV

مشروع مستقل لإعادة بناء تجربة Android TV / Google TV بواجهة عربية RTL وأداء خفيف.

> **عزل المستودعات:** هذا المشروع مستقل عن `pq070pq/sas` (SAS PRO) وعن مستودع `al3nkboot/mi5g-tv`. لا يُسمح لهذا المشروع بتعديلهما أو النشر إليهما.

## الهدف
بناء تطبيق تلفزيون (TV Home / Launcher) مع تطبيق جوال مرافق اختياري. يفصل المشروع بين تطبيق التلفزيون وتطبيق الجوال لأن Android يتعامل معهما كتطبيقين وحزمتين منفصلتين.

## المبادئ
- العربية وRTL افتراضيًا.
- دعم الريموت ولوحة المفاتيح واللمس.
- واجهة خفيفة تناسب أجهزة التلفزيون محدودة الموارد.
- لا روت ولا تعطيل أو حذف لتطبيقات النظام.
- لا تغيير صامت لتطبيق HOME الافتراضي؛ الاختيار للمستخدم.
- لا بيانات طقس أو صلاة أو أخبار وهمية.
- لا يُعلن عن APK جاهز قبل نجاح البناء والاختبارات والتحقق من التوقيع.

## الوحدات المخطط لها
- `tv-launcher`: واجهة التلفزيون وHOME.
- `phone-companion`: تطبيق الجوال الاختياري.
- `core-design`: الهوية ومكونات الواجهة.
- `core-settings`: الإعدادات والتخزين المحلي.
- `feature-home`: الصفحة الرئيسية والمفضلة.
- `feature-prayer`: مواقيت الصلاة والتنبيهات الاختيارية.
- `feature-weather`: الطقس عبر مصدر موثوق.
- `feature-media`: التطبيقات والوسائط المفضلة.

## الحالة
مرحلة التأسيس. لم يُنشأ APK بعد ولم يُختبر على جهاز تلفزيون فعلي.
